# 50-设计系统与视觉规范详设

> DOC-UX-004 | YuTong 设计系统与视觉规范 | 品牌契约落地

## 1. 色彩系统

- 主色 color-primary: #2563EB (yt-blue-600)
- 语义色: success #16A34A / warning #D97706 / danger #DC2626 / info #2563EB
- 中性色阶 50-900，背景 bg-page #F6F8FB

CSS 变量映射：

```css
:root {
  --yt-color-primary: #2563EB;
  --yt-color-success: #16a34a;
  --yt-bg-page: #f6f8fb;
  /* yutong 前缀别名（与 --yt-* 同值，满足 yutong 前缀规则） */
  --yutong-primary: var(--yt-color-primary);
  --yutong-bg-page: var(--yt-bg-page);
  /* Element Plus 变量覆盖 */
  --el-color-primary: var(--yt-color-primary);
  --el-bg-color: var(--yt-bg-card);
}
```

> 规范：所有组件禁止硬编码色值，必须使用 --yt-color-primary 及 Element Plus 变量覆盖 方式引用。

## 2. 间距与网格

- 基准 4px 网格，space-xs 4px / sm 8px / md 16px / lg 24px / xl 32px
- 栅格 12 列，容器 max 1440px，卡片圆角 8px，阴影 card

## 3. 视觉签名

- 主视觉签名：构件蓝图式层级 — 网格 + 细线描边 + 蓝图节点，体现工业构件感
- 层级 规则：信息层级通过字重/字号/色阶/留白四维建立，标题 20/18/16，字重 600/500/400
- 层级 校验：页面需通过 5 档层级走查（标题/分区/卡片/表单/操作）

## 4. 可访问性

- 对比度满足 WCAG AA (4.5:1 正文 / 3:1 大字)
- Lighthouse a11y ≥ 90，键盘可达、焦点可见、语义化标签
- 全局样式：.sr-only / .skip-link / :focus-visible / prefers-reduced-motion

## 5. 字体与排版

- 字体栈：Inter / PingFang SC / Microsoft YaHei
- 场景化字号 12/14/16/20，行高 1.5

## 6. 引用

- 本文档为 53/54/56/66/76 的设计基座。
