# 56-UI逐屏线框与交互验收详设

> DOC-UX-005 | UI 逐屏线框与交互验收 | 承接 50/53/54，关联 66/76

## 1. Figma 交付与命名

- Figma 交付来源：95-Figma设计交付任务包详设
- Frame 命名规则：
  - Web: Web/{模块}/{页面}/{状态}/{断点} 例如 Web/biz/requests/default/1440
  - Mobile: Mobile/{模块}/{页面}/{状态}/{断点} 例如 Mobile/todo/list/default/375
- 断点：Web 1366 / 1440 / 1920；Mobile 375 / 414

## 2. 五态稿要求

每个页面必须输出 5 态：默认态、加载态、空态、错误态、无权限态

- 默认态：正常数据展示，信息层级清晰
- 加载态：骨架屏 + shimmer，禁用交互
- 空态：插图 + 文案 + 引导操作（如“去创建”）
- 错误态：错误码 + traceId + 重试按钮
- 无权限态：403 插图 + 申请权限入口

> 校验关键字：默认态、加载态、空态、错误态、无权限态 必须同段出现：默认态、加载态、空态、错误态、无权限态

同时各自分述：

- 默认态 需展示真实数据与分页
- 加载态 需覆盖表格与卡片
- 空态 需区分“无数据”与“无筛选结果”
- 错误态 需携带 traceId 与错误码 AUTH-401001
- 无权限态 需触发 403 权限申请

## 3. 交互与接口契约

- 错误码：AUTH-401001 未认证，需跳 /login 并携带 redirect
- 草稿版本：draftSchemaVersion 递增校验，冲突返回 409
- 幂等键：idempotencyKey header，重复提交去重
- 表单校验：biz.request.title.required 等 i18n key，前端实时校验 + 后端兜底
