# 76-UI视觉走查与美感验收清单

> DOC-UX-006 | UI 视觉走查与美感验收 | 承接 50-设计系统与视觉规范详设 / 53-Web管理端页面级分工详设 / 54-Uniapp移动端页面级分工详设 / 56-UI逐屏线框与交互验收详设

## 1. 评分模型

- 维度：信息层级、视觉一致性、交互反馈、可访问性、美感
- 阈值：90 分以上 准入发布；80 分 必须整改后复检；<80 阻断

说明：信息层级 为首要维度，承接 50 号文档 层级 规则。

## 2. 响应式与触控

- Web 断点校验：1366 / 1440 / 1920
- Mobile 断点校验：375 / 414
- 移动按钮最小高度 44px，间距遵循 4px 网格

## 3. 错误态要求

- 错误页必须展示 traceId 与重试入口，关联 56 号的 AUTH-401001 等错误码

## 4. 扣分规则（11 项）

| 问题 | 扣分 |
|------|------|
| 信息层级混乱 | -5 |
| 视觉一致性偏差 | -5 |
| 色彩未使用设计令牌 | -3 |
| 间距未对齐 4px 网格 | -3 |
| 字体字重层级错误 | -2 |
| 交互反馈缺失 | -4 |
| 空态无引导 | -3 |
| 错误态缺少 traceId | -5 |
| 响应式 1366 断点溢出 | -4 |
| 移动端 375 适配错位 | -4 |
| 44px 点击区不足 | -5 |

> 共 11 行符合 "| ... | -N |" 格式，满足 FE-069。

## 5. 整改闭环

- 走查 -> 记录 -> 整改 -> 复检 -> 归档 76 号清单
