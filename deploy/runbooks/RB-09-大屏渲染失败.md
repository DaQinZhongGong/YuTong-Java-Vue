# RB-09: 大屏渲染失败 / 数据源异常

> 设计来源: 42-报表与大屏可视化设计、63-生产部署运维 Runbook 详设
> 关联组件: DashboardDesigner / DashboardFullscreen / DatasetEngine / RptDashboard
> 告警: 暂无独立告警，依赖用户反馈或前端埋点异常上报

## 现象

- 大屏设计器保存后，全屏预览页面空白或组件不渲染
- 大屏中图表显示「暂无数据」或加载动画持续旋转
- 某些数据集切换后，所有关联组件同时报错
- 自动轮播过程中页面卡顿或浏览器崩溃

## 排查步骤

### 1. 确认布局 JSON 有效性

```bash
curl -s "http://localhost:20010/api/v1/reports/dashboards/${DASHBOARD_CODE}" \
  -H "Authorization: Bearer ${TOKEN}" | jq '.data.layoutJson'
```

检查：
- `layoutJson` 是否为合法 JSON
- `canvas.width` / `canvas.height` 是否为合理数值（如 1920/1080）
- `components` 数组中每个元素的 `type`、`layout.x/y/w/h` 是否完整

### 2. 检查数据集状态

```bash
curl -s "http://localhost:20010/api/v1/report/datasets/${DATASET_CODE}" \
  -H "Authorization: Bearer ${TOKEN}"
```

关注：
- 数据集 `status` 是否为 ACTIVE
- `dataSourceCode` 对应的数据源是否在线（参照 46-多数据源设计）
- SQL / API 配置是否被修改导致语法错误

### 3. 检查 DatasetEngine 执行日志

后端日志关键词：
```
DatasetEngine.execute
RptDataset.query
DataSourceRouting
```

常见异常：
- `SQLSyntaxErrorException`: 数据集 SQL 语法错误
- `DataSourceNotFoundException`: 数据源编码不存在或已删除
- `QueryTimeoutException`: 查询超时，检查慢 SQL 或增加超时配置

### 4. 前端性能排查

打开浏览器 DevTools：
- Network: 确认 `/api/v1/report/datasets/{code}/data` 请求返回 200 且有数据
- Console: 检查 ECharts 初始化错误（如 `dom` 不存在、option 格式错误）
- Performance: 组件过多（>30 个）或轮播间隔过短（<5s）可能导致渲染压力

### 5. 检查权限与 License

大屏所属模块为 `report`，需要校验：
```bash
curl -s "http://localhost:20010/api/v1/license/modules" \
  -H "Authorization: Bearer ${TOKEN}" | jq '.data.report'
```
若 `report` 模块未激活，大屏功能将被拦截。

## 常见原因与修复

| 原因 | 修复方案 |
|------|---------|
| layoutJson 损坏或被截断 | 从数据库备份恢复，或重新在设计器中编排布局 |
| 数据集 SQL 语法错误 | 进入报表设计器，修正数据集 SQL 并预览验证 |
| 数据源离线 | 参照 46-多数据源设计检查数据源健康状态，切换备用数据源 |
| ECharts 组件 type 不匹配数据格式 | 检查组件 type（如 pie-chart 需要 category + value 两列数据） |
| 浏览器内存不足（组件过多） | 减少单屏组件数量，拆分为多个大屏，或使用分页轮播 |
| 自动刷新间隔过短 | 将 refreshInterval 调整为 >= 30 秒，避免频繁请求 |

## 回滚

若发布后的全屏大屏异常，可回退到上一版本布局：
```sql
-- 查询历史 layoutJson（若已开启审计）
SELECT content FROM operation_log
WHERE module = 'report' AND biz_type = 'dashboard'
  AND biz_id = '${DASHBOARD_CODE}'
ORDER BY created_time DESC LIMIT 1;
```

## 验证

修复后：
1. 设计器中预览正常渲染
2. 全屏预览 `/dashboard-fullscreen/{code}` 无报错
3. F12 Console 无 ECharts 红色错误
4. 自动轮播流畅，内存占用稳定
