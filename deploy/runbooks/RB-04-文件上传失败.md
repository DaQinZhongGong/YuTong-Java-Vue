# RB-04 文件上传失败 Runbook

> 适用: MinIO 不可达、签名失败、文件大小超限、上传 5xx
> 优先级: P1 | 影响: 申请单附件、AI 知识库文档、头像上传 | 设计来源: 33/63

## 1. 现象

- 前端上传接口 `/api/v1/files/upload` 返回 500 / 502 / 504。
- 应用日志出现 `MinioException` / `ErrorResponseException` / `connect timed out`。
- `/actuator/health` 返回 `{"minio":{"status":"DOWN"}}`（如配置了健康指示器）。
- MinIO 控制台无法访问（http://localhost:9001）。
- 上传进度卡在 99% 或立即报错。

## 2. 影响范围

- 申请单附件无法上传，业务流程阻塞。
- AI 知识库文档无法入库，RAG 检索数据陈旧。
- 用户头像、Excel 导入等功能不可用。
- 已上传文件读取正常（除非 MinIO 完全宕机）。

## 3. 快速判断命令

```bash
# 1) MinIO 容器状态
docker ps --filter "name=yutong-minio" --format "{{.Names}}\t{{.Status}}\t{{.Ports}}"

# 2) MinIO 健康（HTTP 200 = ok）
curl.exe -s -o NUL -w "%{http_code}\n" http://localhost:9000/minio/health/live

# 3) 控制台可达性
curl.exe -s -o NUL -w "%{http_code}\n" http://localhost:9001/

# 4) 应用 -> MinIO 连通性
docker exec yutong-boot sh -c "curl -s -o /dev/null -w '%{http_code}' http://yutong-minio:9000/minio/health/live"

# 5) mc 客户端检查
docker run --rm --network yutong-net \
  -e MC_HOST_yutong=http://minioadmin:minioadmin@yutong-minio:9000 \
  minio/mc:latest sh -c "mc admin info yutong && mc ls yutong/"

# 6) 磁盘空间
docker exec yutong-minio df -h /data

# 7) Bucket 列表
docker run --rm --network yutong-net \
  -e MC_HOST_yutong=http://minioadmin:minioadmin@yutong-minio:9000 \
  minio/mc:latest mc ls yutong/
```

## 4. 关键日志位置

| 位置 | 内容 |
| --- | --- |
| `docker logs yutong-minio` | MinIO 启动、磁盘满、ERASURE 编码错误 |
| `docker logs yutong-boot` | io.minio 异常栈、上传超时 |

## 5. 回滚或临时降级方案

### 5.1 MinIO 重启（数据保留）

```bash
# 1) 检查 volume 挂载（确认数据卷）
docker inspect yutong-minio --format '{{range .Mounts}}{{.Source}} -> {{.Destination}}{{println}}{{end}}'

# 2) 重启
docker restart yutong-minio
sleep 15
curl.exe -s http://localhost:9000/minio/health/live

# 3) 验证 bucket 完整性
docker run --rm --network yutong-net \
  -e MC_HOST_yutong=http://minioadmin:minioadmin@yutong-minio:9000 \
  minio/mc:latest mc ls yutong/ --recursive
```

### 5.2 切换到本地文件系统降级（紧急）

```yaml
# application.yml 临时配置
yutong:
  storage:
    type: local           # 从 minio 降级到 local
    local:
      base-dir: /data/yutong-files
    minio:
      enabled: false
```

```bash
# 重启应用生效
docker restart yutong-boot
```

> 注意: 降级到 local 后，多实例不共享文件，仅作单实例紧急方案。

### 5.3 静态资源回滚（前端镜像异常）

```bash
# 1) 回滚 web-admin 镜像
docker stop yutong-web-admin && docker rm yutong-web-admin
docker pull yutong-web-admin:{prev_version}
docker run -d --name yutong-web-admin \
  --network yutong-net \
  -p 80:80 \
  yutong-web-admin:{prev_version}

# 2) 健康检查
curl.exe -s -o NUL -w "%{http_code}\n" http://localhost/healthz.html
```

### 5.4 文件大小/类型策略临时放宽

```yaml
yutong:
  storage:
    max-file-size: 100MB    # 从 50MB 临时放宽
    allowed-types: [jpg, png, pdf, docx, xlsx, zip, mp4]
```
